# 第三问 V2 最终算法与结果口径

V2 已于 2026-09-26 经用户确认作为最终方案；本文描述的是实际交付并得到官方评分的 V2，不包括后续整数规划或公式驱动优化的研究设计。

本文档描述 **V2 最终版本**。旧方法和旧数值存放在 `算法与结果说明_V1_原始方案.md` 与 `results_problem3_v1_original/`；论文应从 `results_problem3_v2_final/` 取数。

## 题目目标

在场景 B 下同时确定计算 DAG 的子图切分、每个子图所属核心以及各核心执行顺序。对 1～5 核分别评估无 L2 和共享只读 L2。主要目标是缩短 Makespan，即最后一个操作的完成时刻；额外搬运字节数作为同 Makespan 时的次级目标。L2 容量为 1 MiB，读取带宽 250 B/cycle，DDR 读取带宽 60 B/cycle，跨核复制等待 500 cycle，以给定配置和官方评估器为准。

## V1 到 V2 的改进

V1 生成通信亲和、共享张量分散、私有缓存聚类、重排和局部切图候选。它使用按子图顺序的 FIFO 代理模型给候选排序，再由官方评估器决定是否接受。代理模型没有完整模拟 COPY_IN 并发和溢出重载，因此在存在大量 L1/UB spill 的图上可能严重低估 L2 流量。

V2 不修改官方评估器，也不把代理预测当作成绩。它直接读取 V1 已保存的第三问官方 `per_core_timeline`：

1. 找到最晚结束的核心，作为 Makespan 的直接瓶颈候选。
2. 按该核心各子图的官方 DDR miss 字节数和执行时长排序，优先挑选真实代价高的子图。这里读取的是官方逐 COPY_IN 记录及原图张量大小；缓存命中字节另作较小权重，仅决定搜索顺序。
3. 对高代价子图尝试同核提前或延后 1、2、4 个位置，以改变发射时机、流水线交叠及 L2 FIFO 复用窗口。若别的核结束得明显更早，再尝试把子图移到空闲较多的核。
4. 给图依赖和每核顺序同时加边，拓扑排序检查是否会成环。无效的调度不送给评估器。
5. 用赛题第三问官方程序正式评分。仅当 `(Makespan, added_copy_bytes)` 按字典序严格变小，才更新当前最好方案；成功后再利用新时间线搜索下一轮。默认每组最多新增 4 次官方评分。

V2 对超大图采用明确的资源保护：非 COPY 算子超过 10,000 个时沿用已通过官方评分的 V1 结果，不运行会占用大量内存的 Python 邻域构造。1 核也直接沿用 V1；这两类配置都仍计入 V2 的完整 500 组最终表。没有找到更好方案的其他配置同样保留 V1。`summary.json` 的 `search_profile` 和 `selected_source` 分别标明搜索范围及最后来源。

这个策略的优势是把额外计算预算集中在**官方实际测出的瓶颈**上，而不是依赖误差较大的缓存预测。它保持原解作为可证明的性能下界（对本次启发式结果而言），并且每次改善均能通过候选时间线、缓存事件和方案文件追溯。它仍是有限邻域搜索，不保证全局最优。

## 数值如何得到

- `results_problem3_v1_original`：优化前已完成的 500 组方案和官方结果。其原始数字被保留。
- `results_problem3_v2_final/case_NNN_Kcores/summary.json`：同一组 `original_v1` 与 `best`，以及是否发生 V2 替换。
- `results_problem3_v2_final/V1_vs_V2_comparison.csv`：逐 case、逐核比较 V1 和 V2 的 Makespan、额外搬运量、缓存命中字节率及新增评分次数。
- `results_problem3_v2_final/comparison_100cases.csv` 与 `appendix_100cases.csv`：**仅为 V2 最终方案**的无 L2 与只读 L2 对比；与 V1 对照时不要从这里误读为 V1 原始结果。
- 曲线 CSV 按 100 个 case 的逐项比值求平均，而不是平均 Makespan 再求比。具体字段见 `README.md`。

每组的 `best_plan.json` 给出 `node_to_subgraph` 和 `core_schedules`，`best_result.json.gz` 无损保存官方评估输出，其中有 `makespan`、`data_movement_bytes`、`cache_stats`、`cache_events` 和 `per_core_timeline`。校验程序逐组核对方案结构、表格与官方结果的一致性，并检查 V2 不劣于 V1。
