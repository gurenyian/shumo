# 5.1 Region初始化

规则：

最大串行链。

# 5.3 Fusion评价

对于：

Region A,B


考虑：

Merge(A,B)



收益：


## Communication Benefit


减少未来跨Core COPY。


计算：

Tensor size。


---

## Tensor Reuse Benefit


A产生Tensor。

B立即使用。


融合：

Tensor驻留。


---

## Pipe Benefit


M/V互补。


---

损失：


## Parallel Loss


融合减少并行。


---

## Lifetime Cost


融合增加Tensor生命周期。


导致：

Peak L1/UB增加。



最终：


Gain


=

CommBenefit

+

ReuseBenefit

+

PipeBenefit

-

ParallelLoss

-

LifetimeCost
